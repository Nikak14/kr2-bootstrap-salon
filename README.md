# Новый образ

Учебный сайт женской и мужской парикмахерской для практических занятий №9–11 и контрольной работы №2 по дисциплине «Фронтенд и бэкенд разработка».

Проект выполнен в отдельном репозитории на Bootstrap 5.3.3. Данные студии, цены, фотографии и метка на карте демонстрационные. Действующего салона по этому адресу нет.

## Практическое занятие №9

- Создана отдельная папка проекта и главная страница `index.html`.
- Bootstrap CSS и JS Bundle подключены через CDN, затем подключён `css/custom.css`.
- Шапка, навигация, hero, преимущества и популярные услуги построены через `container`, `container-fluid`, `row`, `col-12`, `col-md-*`, `col-lg-*` и `g-*`.
- На узком экране карточки идут по одной, на среднем по две, на широком по три.
- Есть адаптивный подвал.

## Практическое занятие №10

- Добавлены `catalog.html`, `product.html`, `order.html` и дополнительная страница `contacts.html`.
- На всех страницах используется единый Bootstrap `navbar`.
- Каталог содержит `card`, `badge`, `btn`, `alert` и вкладки `nav-pills`; также есть `accordion` с ответами на вопросы.
- Страница услуги показывает описание, длительность, цену и таблицу характеристик.
- Модальное окно `modal` показывает выбранную услугу и ведёт к записи.
- Форма записи использует `form-control`, `form-select`, `input-group`, `form-check`, проверку обязательных полей и сообщения `alert`.

## Практическое занятие №11 и контрольная работа №2

- Проверена структура проекта, ссылки между страницами, подключение Bootstrap, сетка и компоненты.
- Форма позволяет выбрать дату в ближайшие 60 дней и свободное время. Демонстрационные записи сохраняются в `localStorage` этого браузера, видны в списке и могут быть удалены. Телефон и комментарий не сохраняются. Серверной отправки и реального бронирования нет.
- На главной и странице студии встроена Яндекс Карта с демонстрационной точкой в центре Москвы. Это не адрес салона.
- Подвал по структуре и двойная стрелка «Наверх» выполнены по примеру [Bootstrap-сайта AquaWave](https://github.com/MrDary-art/kr2-bootstrap-shop): стрелка появляется после прокрутки и возвращает к началу страницы.
- Добавлены женские и мужские услуги, галерея, страница студии, видимый фокус клавиатуры, подписи форм, `alt` у изображений и адаптивные изображения.

## Запуск и проверка

Откройте `index.html` в браузере или запустите из папки проекта:

```powershell
python -m http.server 8000
```

После этого откройте `http://localhost:8000/`. Для проверки формы: перейдите в «Записаться», заполните поля, выберите дату и время, сохраните запись. Список «Мои записи» покажет результат; повторное использование занятого интервала блокируется в этом браузере. Для проверки модального окна нажмите «Записаться» на карточке услуги. Для проверки адаптивности откройте DevTools на ширинах 390, 768 и 1440 пикселей.

Bootstrap загружается по сети через CDN. Яндекс Карта и шрифты тоже требуют подключения к интернету.

Фотографии в `images/` сгенерированы для учебного макета и не показывают реальных мастеров, клиентов или помещение студии.
